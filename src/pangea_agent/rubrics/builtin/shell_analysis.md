# sh/Bash 源码分析

支持 POSIX sh 与 Bash；先核对 shebang、调用方使用的解释器及运行契约。Bash 解析器可提供结构，但解析成功不证明 POSIX sh 兼容；没有 shebang 的 .sh/.bash 文件需按实际调用证据确认方言。不要把 zsh、fish、PowerShell 当成本规则覆盖范围。
仅阅读冻结源码，不执行脚本、source、eval 或命令替换。检查引用与分词、通配符、空值/未设置变量、位置参数、退出状态、管道状态、重定向、临时文件、trap 与信号清理、工作目录和环境继承。set -e 在条件、管道、子 shell 中的行为必须结合实际上下文，不能假定任何失败都会中止。

从业务入口追踪外部命令的 argv、环境、工作目录、输入输出、退出码与恢复。区分静态命令文本和已确认的目标；变量、PATH、eval、命令替换或运行时配置决定的目标缺证据时保留待确认。source/. 的相对路径按调用环境判断，不按文件名强行连边。

与 Python/C 交互时核查参数引用、stdout/stderr 协议、非零退出码传播、超时/信号、半写文件、重复调用和清理。测试必须说明外部刺激、观测与恢复；不得执行用户脚本来建立索引，也不得宣称语法解析就是运行验证。
