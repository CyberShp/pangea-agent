# Python 源码分析

只分析冻结源码及明确的运行契约；AST 是导航信息，不执行 import、不运行目标脚本。
按目标入口梳理正常流程、条件分支、异常传播、资源清理和恢复。检查参数与配置解析、路径与编码、bytes/str、默认可变参数、异常被吞、上下文管理、迭代器及异步取消；仅在源码相关时展开。

外部进程调用需阅读实际 argv、shell 参数、cwd、env、stdin/stdout/stderr、超时、wait/returncode/check 及清理逻辑。区分列表参数和字符串命令；动态命令、导入、插件与反射的真实目标无法由冻结证据确认时记为待确认，不猜测调用边。
ctypes/cffi/扩展模块与 C 交互时核对参数宽度、符号、编码、长度、所有权、回调生命周期、错误码及 ABI。未提供绑定/构建证据时不声称目标已经解析。
