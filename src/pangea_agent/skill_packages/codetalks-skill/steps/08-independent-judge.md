# Step 08：独立审查

## 目标

在 `活文档/` 和 `内部索引/` 中完成审查：

- `活文档/19-独立审查报告.md`
- `活文档/覆盖门禁/最终覆盖门禁.md`
- `内部索引/独立审查状态.json`

本步骤不得写入 `正式输出/覆盖审计与分析限制.md`。

读取并执行 `references/worker-judge-protocol.md`。深度型必须使用真实独立 Judge；速度型如实记录自审。审查方法、候选驳回记录和语义结论分别记录；`independent=true` 或步骤通过本身不能证明结论正确。

审查完成后才进入 Step 09。未解决争议保留 UNRESOLVED，在正式报告中呈现，不能以交付结构完整宣称语义通过。
